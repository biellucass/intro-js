## 📋 Sobre o Projeto

Este projeto tem como objetivo consolidar os conceitos fundamentais de JavaScript aplicados à web. Aqui você encontrará códigos focados na manipulação do DOM, lógica de programação básica, eventos, interatividade e integração com HTML e CSS.
